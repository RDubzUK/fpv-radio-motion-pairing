# PropNutz branding assets

The workspace uses the PropNutz website's charcoal, paper, red and blue palette,
Barlow typography and text wordmark treatment. The companion layout is authored
for this tool; reference: https://www.propnutz.co.uk/ (7 October 2026).

The favicon is a local PN monogram using the companion wordmark's colours.

Barlow and Barlow Condensed are by Jeremy Tribby and distributed under the SIL
Open Font License 1.1. Local font files were obtained from Google Fonts. Both
original license files are included under `fonts/`. They remain available when
the local/LAN app or packaged Windows version has no internet connection.

- https://fonts.google.com/specimen/Barlow
- https://fonts.google.com/specimen/Barlow+Condensed
- https://github.com/google/fonts/tree/main/ofl/barlow
- https://github.com/google/fonts/tree/main/ofl/barlowcondensed

No footage, session data or telemetry is sent to the PropNutz website by the
branding. Community links open the website only when clicked.
